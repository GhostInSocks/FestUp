# 📌 O projektu
Namen projekta je rešiti pogost problem za ljubitelje glasbe in festivalov: kako najti družbo, ter dobiti realne informacije o sami izkušnji.
Platforma združuje funkcionalnosti odkrivanja dogodkov, skupnostnega povezovanja (forumi/oglasna deska) in natančnega ocenjevanja (venues, izvajalci, ponudba na lokaciji). 
Dodatno: Vključuje tudi AI chatbota, ki uporabnikom pomaga pri hitrem pregledu mnenj

## Ključne funkcionalnosti
### 🎟️ Odkrivanje dogodkov in informacije
•	Pregled aktualnih glasbenih festivalov in koncertov
•	Osnovne informacije o dogodku, lokaciji, nastopajočih in povezave do uradne nakupa kart
### 🤝 Skupnost
•	Tematski forumi/deske pod vsakim dogodkom: Uporabniki lahko objavljajo ponudbe in povpraševanja za:
o	Delitev prevoza (carpool)?
o	Združevanje za kampiranje ali iskanje skupine za obisk dogodka
o	Splošne debate in organizacijo pred dogodkom
### ⭐ Večkriterijsko ocenjevanje
•	Ocenjevanje celotnega dogodka ter posameznih kategorij:
o	Prizorišče / Venue (dostopnost, zvok, prostornost)
o	Nastopajoči / Izvajalci (izvedba, atmosfera)
o	Dodatna ponudba (hrana, pijača, sanitarije, kamp)
•	Pisne recenzije in ocene skupnosti
### 🤖 AI Chatbot Asistent
•	Povzetek mnenj (Review Recap): Chatbot analizira ocene ter uporabniku poda hitro sintezo pozitivnih in negativnih strani dogodka/prizorišča
### 👤 Uporabniški profili
•	Nastavitve profila, upravljanje lastnih objav in ocen
•	Pregled shranjenih dogodkov in preteklih obiskov
### 🛠️ Tehnološki nabor (Tech Stack)
•	Frontend: React / Next.js (Splet), React Native ali Flutter (Mobilna aplikacija)
•	Backend: Node.js / Python (FastAPI/Django) / Go
•	Baza podatkov: PostgreSQL / MongoDB
•	AI / Chatbot: OpenAI API / LangChain (ali druga LLM integracija)
